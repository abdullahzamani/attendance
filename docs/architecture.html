Staff Movement System

Records when staff leave the office and come back, shows who is out on a wall board, and turns the log into daily, monthly and yearly reports. It is one Laravel application: an admin panel and a display board on top of the same models and database.

  • PHP 8.3+
  • Laravel 13
  • Filament 5 admin panel
  • Livewire 4 board
  • SQLite or MySQL
  • PHPUnit + GitHub Actions

Request path

What happens when a clerk clicks Check out

  1. The modal opens with the shared form.Staff (only people currently in the office), reason (only active reasons), out time defaulting to now, optional expected return and note.app/Filament/Actions/MovementActions.php
  2. Livewire sends the form to the server.The request carries the session cookie and CSRF token; a guest would be sent to the login page.bootstrap/app.php · Filament panel middleware
  3. Filament validates the fields.Required fields, and the expected return must be after the out time. Errors show inline in the modal.
  4. CheckOutStaff applies the rule that matters.Inside a transaction it locks the staff row, then refuses if that person already has an open movement, so two clerks can't check out the same person at once.app/Actions/CheckOutStaff.php
  5. A movement row is inserted with no in_at.It records who checked the person out, for the audit trail.movements.checked_out_by
  6. The clerk sees a toast, and the screens catch up.The dashboard updates within 30 seconds and the wall board within 15 seconds, on their next poll.app/Filament/Widgets · app/Livewire/Board.php

Repository

Where each part lives

app/Actions/
CheckOutStaff and CheckInStaff: the business rules, independent of any screen.
app/Models/
Staff, Unit, MovementReason, Movement, User, with relations and the open / overdue logic.
app/Policies/
Admin-only rules for master data; staff and movement rules for clerks.
app/Filament/Resources/
One folder per screen, split into Schemas (forms), Tables and Pages.
app/Filament/Actions/MovementActions.php
The shared Check out and Check in buttons.
app/Filament/Widgets/
Dashboard stats and the Currently out table.
app/Livewire/Board.php
The wall board, with its view in resources/views/livewire/board.blade.php.
database/migrations/ · seeders/
The schema as code; first admin, units and reasons; DemoSeeder for sample data.
tests/Feature/
16 tests: check-out rules, permissions, screens, CSV export, board.
.github/workflows/tests.yml
Runs the tests on PHP 8.3 and 8.4 for every push and pull request.
